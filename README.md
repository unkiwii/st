# st - simple terminal

A fork of https://git.suckless.org/st with some changes:

- Inconsolata font
- zsh as the shell
- gruvbox dark and light colorscheme
- Update colorscheme to light or dark with Shift+Ctrl+Backspace (it reads ~/.config/current_background)
- Open URL under cursor when pressing Left Control and Mouse Button 1
- `make clean` removes `config.h` so is recreated from `config.def.h` with `make`
